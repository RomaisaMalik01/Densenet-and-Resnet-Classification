# DenseNet and ResNet Image Classification

An end-to-end PyTorch implementation comparing **DenseNet** and **ResNet** architectures for image classification tasks. This repository covers dataset loading, data preprocessing/augmentation, model training, performance evaluation, and visualization.

---

##  Features

- **Architectures**: Comparative implementation of **ResNet** (e.g., ResNet-18/50) and **DenseNet** (e.g., DenseNet-121).
- **Transfer Learning**: Pre-trained backbones leveraged for faster convergence and higher accuracy.
- **Data Augmentation**: Built-in image transforms including resizing, normalization, random flips, and rotations.
- **Performance Evaluation**: Visualizations for loss curves, accuracy metrics, and confusion matrices.
- **Jupyter Notebook Workflow**: Interactive code structure for easy execution and modification.
